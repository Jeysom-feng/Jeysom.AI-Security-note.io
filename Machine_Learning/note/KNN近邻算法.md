# KNN邻近算法：
1.回归问题：求距离后，将前n项求平均

2.分类问题：求距离后，在前n项中进行投票表决，票数的多的将其置为该条样本的标签

3.聚类问题：

## 距离的分类：
1.欧氏距离：用勾股定理求距离，对应维度坐标差值的平方和再开根号

2.曼哈顿距离（城市街区距离）：对应维度坐标的差值

3.切比雪夫距离：每个维度的坐标差值的最大值

4.闵氏距离：对应维度坐标差值的p次方和再开p次根



## 调用的包：
 KNN近邻算法

   回归问题：用KNeighborsRegressor类，参数：n_neighbors

   分类问题：KNeighborsClassifier类，参数：n_neighbors
