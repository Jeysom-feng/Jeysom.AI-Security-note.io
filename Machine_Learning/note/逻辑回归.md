#### 原理：
数据经过线性回归后得到预测值，将预测值交给sigmoid函数，会给出一个0-1间的数（概率），基于给出的阈值做出分类，是解决二分类的方式



#### 损失函数：

对公式的理解：损失函数计算的是模型预估的值所得出的概率是否与现实差距过大。

若一个样本的真实标签为1，但是模型预测出的值经过激活函数sigmoid后给出的概率要越接近0，那么说明模型对正例的丢失率过高，越接近1，说明模型几乎不会丢失正例。而真正标签为0时，模型预测出的值经过激活函数sigmoid后给出的概率要越接近1，说明模型错判的概率极高，可以理解为模型在线性回归时拟合的不是很好，可以结合梯度下降优化算法来优化权重w和偏置b。



#### 混淆矩阵：
confusion_matrix

| | 正例（预测） | 反例（预测） |
| --- | --- | --- |
| 正例（真实） | 真正例 | 伪反例 |
| 反例（真实） | 伪正例 | 真反例 |


精确率：真正例/（真正例+伪正例）

函数：precision_score(参数一：标签真实值，参数二;标签预测值，参数三：正例的标签)

召回率：真正例/（真正例+伪反例）

函数：recall_score(参数一：标签真实值，参数二;标签预测值，参数三：正例的标签)

F1：2*精确率*召回率/（精确率+召回率）

函数：F1_score(参数一：标签真实值，参数二;标签预测值，参数三：正例的标签)



#### ROC曲线：
TPR（真正率）：正样本中被预测为正样本的概率

FPR（假正率）：负样本中被预测为正样本的概率

AUC：曲线下面积
