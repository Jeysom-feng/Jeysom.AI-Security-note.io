

### 迁移攻击：
在黑盒攻击时，连续查询会被对方在网络层察觉，迁移攻击能够很好的解决这一点

#### 过程：
当试图攻击对方A模型时，我们可以先训练一个本地模型B，对B进行白盒攻击，将产生的对抗样本迁移到模型A进行测试

#### 在迁移攻击中当A比B模型强时，迁移攻击效果往往更好，
##### 原因：
A模型的决策边界尖锐、复杂、高度特化；B模型的决策边界平滑、简单、通用；

生成扰动时，过度拟合A的边界，迁移性较好差，B模型能更好捕捉共性弱点，迁移性强



### 查询攻击：
查询攻击有NES、ZOO、Bandits

#### Bandits：NES+随机降维采样
##### 流程：
构造投影矩阵P，将样本降维，再随机采样，采样次数与维度成正相关，采样完后根据公式算出近似梯度，再映射回高维空间，对样本进行更新

##### 伪代码示例：
```plain
输入：原始样本 x ∈ R^d，真实标签 y，查询预算 Q
超参：低维维度 q，采样数 n，步长 α，扰动尺度 σ，范数 p

1. 构造投影矩阵 P ∈ R^{d×q}
   （DCT低频随机基 或 高斯随机矩阵）

2. x_adv ← x
3. queries ← 0

4. while queries < Q:
     # 4.1 低维采样 + 对称查询
     采样 u_1,...,u_n ~ N(0, I_q)
     for i = 1 to n:
         δ_i ← P·u_i / ||P·u_i||        # 投影+归一化
         l_i^+ ← Loss(x_adv + σ·δ_i, y)  # 正方向查询
         l_i^- ← Loss(x_adv - σ·δ_i, y)  # 负方向查询
         queries += 2

     # 4.2 估计低维梯度
     g_u ← (1/(2nσ)) · Σ_{i=1}^n (l_i^+ - l_i^-) · u_i

     # 4.3 投影回高维
     g_x ← P · g_u

     # 4.4 梯度更新 + 投影回可行域
     x_adv ← Π_{B_p(x,ε)∩[0,1]} ( x_adv - α · g_x / ||g_x|| )

     # 4.5 早停判断
     if Model(x_adv) ≠ y:
         攻击成功，break

5. return x_adv

```

##### 公式：

$$

\begin{align}
& P \in \mathbb{R}^{d \times q},\ q \ll d
&& \text{（随机投影矩阵：}d\text{维输入} \to q\text{维低维子空间）} \\[4pt]
& u_i \sim \mathcal{N}(0,\ I_q),\ i = 1,\dots,n
&& \text{（低维高斯采样：在}q\text{维子空间采随机方向）} \\[4pt]
& \delta_i = \frac{P u_i}{\|P u_i\|_2}
&& \text{（投影回高维并归一化，得到}d\text{维扰动方向）} \\[4pt]
& l_i^+ = L(x_t + \sigma\delta_i,\ y)
&& \text{（正方向查询：加扰动后的损失）} \\[4pt]
& l_i^- = L(x_t - \sigma\delta_i,\ y)
&& \text{（负方向查询：减扰动后的损失）} \\[4pt]
& \hat{g}_u = \frac{1}{2n\sigma}\sum_{i=1}^{n}(l_i^+ - l_i^-)\,u_i
&& \text{（低维NES梯度估计：对称差分加权平均）} \\[4pt]
& \hat{g}_x = P\,\hat{g}_u
&& \text{（梯度投影回高维：}q\text{维} \to d\text{维像素空间）} \\[4pt]
& x_{t+1} = \Pi_{\mathcal{B}_p(x_0,\epsilon)\cap[0,1]^d}\!\left(x_t - \alpha\frac{\hat{g}_x}{\|\hat{g}_x\|_2}\right)
&& \text{（梯度更新：沿负梯度走一步并投影回可行域）} \\[4pt]
& \Pi_{\mathcal{B}_p(x_0,\epsilon)}(x) = x_0 + \epsilon\frac{x-x_0}{\max(\|x-x_0\|_p,\ \epsilon)}
&& \text{（}L_p\text{球投影：约束扰动半径不超过}\epsilon\text{）}
\end{align}

$$
