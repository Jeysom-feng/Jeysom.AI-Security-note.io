### **1. 张量的基本操作**
#### **1.1 创建张量**
+ **PyTorch**:

```python
import torch
# 创建一个随机张量
tensor = torch.randn(3, 4)  # 3行4列的随机张量
```

+ **TensorFlow**:

```python
import tensorflow as tf
# 创建一个随机张量
tensor = tf.random.normal([3, 4])  # 3行4列的随机张量
```

---

#### **1.2 张量的形状操作**
+ **PyTorch**:

```python
# 查看形状
print(tensor.shape)  # 输出: torch.Size([3, 4])

# 改变形状
reshaped = tensor.reshape(2, 6)  # 改为2行6列
```

+ **TensorFlow**:

```python
# 查看形状
print(tensor.shape)  # 输出: (3, 4)

# 改变形状
reshaped = tf.reshape(tensor, [2, 6])  # 改为2行6列
```

---

#### **1.3 张量的元素操作**
+ **PyTorch**:

```python
# 最大值
max_val = torch.max(tensor)

# 最小值
min_val = torch.min(tensor)

# 求和
sum_val = torch.sum(tensor)

# 平均值
mean_val = torch.mean(tensor)
```

+ **TensorFlow**:

```python
# 最大值
max_val = tf.reduce_max(tensor)

# 最小值
min_val = tf.reduce_min(tensor)

# 求和
sum_val = tf.reduce_sum(tensor)

# 平均值
mean_val = tf.reduce_mean(tensor)
```

---

#### **1.4 张量的数学运算**
+ **PyTorch**:

```python
# 加法
result = tensor1 + tensor2

# 矩阵乘法
result = torch.mm(tensor1, tensor2)  # 仅适用于2D张量

# 点积
result = torch.dot(tensor1, tensor2)  # 适用于1D张量
```

+ **TensorFlow**:

```python
# 加法
result = tf.add(tensor1, tensor2)

# 矩阵乘法
result = tf.matmul(tensor1, tensor2)

# 点积
result = tf.tensordot(tensor1, tensor2, axes=1)  # 点积
```

---

#### **1.5 张量的索引和切片**
+ **PyTorch**:

```python
# 索引
element = tensor[0, 1]  # 获取第0行第1列的元素

# 切片
slice_tensor = tensor[1:3, 2:4]  # 获取第1-3行，第2-4列
```

+ **TensorFlow**:

```python
# 索引
element = tensor[0, 1]

# 切片
slice_tensor = tensor[1:3, 2:4]
```

---

#### **1.6 张量的连接与拆分**
+ **PyTorch**:

```python
# 拼接
concatenated = torch.cat([tensor1, tensor2], dim=0)  # 沿着行拼接

# 拆分
split_tensors = torch.split(tensor, 2, dim=0)  # 沿着行拆分
```

+ **TensorFlow**:

```python
# 拼接
concatenated = tf.concat([tensor1, tensor2], axis=0)  # 沿着行拼接

# 拆分
split_tensors = tf.split(tensor, num_or_size_splits=2, axis=0)  # 沿着行拆分
```

---

#### **1.7 改变张量的维度**
+ **PyTorch**:

```python
# 增加维度
unsqueezed = tensor.unsqueeze(0)  # 在第0维增加一个维度

# 减少维度
squeezed = tensor.squeeze(0)  # 删除第0维
```

+ **TensorFlow**:

```python
# 增加维度
unsqueezed = tf.expand_dims(tensor, axis=0)  # 在第0维增加一个维度

# 减少维度
squeezed = tf.squeeze(tensor, axis=0)  # 删除第0维
```

---

#### **1.8 张量的矩阵运算**
+ **PyTorch**:

```python
# 矩阵乘法
result = torch.mm(tensor1, tensor2)  # 仅适用于2D张量

# 点积
result = torch.dot(tensor1, tensor2)  # 适用于1D张量
```

+ **TensorFlow**:

```python
# 矩阵乘法
result = tf.matmul(tensor1, tensor2)

# 点积
result = tf.tensordot(tensor1, tensor2, axes=1)  # 点积
```

---

#### **1.9 张量的数据类型转换**
+ **PyTorch**:

```python
# 转换为浮点型
tensor = tensor.float()

# 转换为整数型
tensor = tensor.long()
```

+ **TensorFlow**:

```python
# 转换为浮点型
tensor = tf.cast(tensor, tf.float32)

# 转换为整数型
tensor = tf.cast(tensor, tf.int64)
```

### **2. 常用API总结**
#### **PyTorch常用API**
+ `torch.randn()`: 创建随机张量
+ `torch.zeros()`: 创建全零张量
+ `torch.ones()`: 创建全一张量
+ `torch.cat()`: 拼接张量
+ `torch.split()`: 拆分张量
+ `torch.mm()`: 矩阵乘法
+ `torch.dot()`: 点积
+ `torch.sum()`: 求和
+ `torch.mean()`: 平均值
+ `torch.max()`: 最大值
+ `torch.min()`: 最小值

#### **TensorFlow常用API**
+ `tf.random.normal()`: 创建随机张量
+ `tf.zeros()`: 创建全零张量
+ `tf.ones()`: 创建全一张量
+ `tf.concat()`: 拼接张量
+ `tf.split()`: 拆分张量
+ `tf.matmul()`: 矩阵乘法
+ `tf.tensordot()`: 点积
+ `tf.reduce_sum()`: 求和
+ `tf.reduce_mean()`: 平均值
+ `tf.reduce_max()`: 最大值
+ `tf.reduce_min()`: 最小值
