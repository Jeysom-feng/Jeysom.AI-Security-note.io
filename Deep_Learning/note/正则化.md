### DropOut(神经元随机死亡)
#### 实现：
设定一个超参p:神经元死亡概率，对未死亡的神经元进行缩放，缩放倍率为1/（1-p）

#### 核心思想：
破坏任意两个神经元之间的共适应性，避免神经元死记硬背训练集的噪声

:::color4
注意：DropOut层只在训练阶段启用，测试时关闭该层

:::

#### 代码实现：
```python
import torch
import torch.nn as nn

dropout = nn.Dropout(p=0.4)
linear1 = nn.Linear(4,5)
input = torch.randn(0,10,size=(10,4)).float
#将数据导入线性层处理
y = linear1(input)
#将线性层处理好数据交给激活函数
y = torch.relu(y)
#进行随机神经元失活处理，处理后未失活神经元对应数据进行缩放
y = dropout(y)
```



### BN(batch normalize)批量归一化
#### 实现:
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1791018880370-595cb47f-8d2e-4274-b66c-dc88043eeba5.png" width="1067.857100424314" alt="" title="" crop="0,0,1,1" id="u0c5cd063" class="ne-image">

在经过线性层计算后，将数据进行标准化（方差为1，均值为0），均值与方差是该批次数据计算得出的

标准化后会损失一些信息，经过缩放与平移（λ，β）后找回一些信息（数据之间的关系）

:::color4
注意：测试时也应该将数据进行BN，均值与方差不用重新计算，采用训练时每个批次的均值与方差的平均值

:::

#### 核心思想：
减轻每个批次之间数据差异过大造成的内部协变量偏移（在训练过程中，网络前面层的参数不断更新，导致后面每一层输入的数据分布持续变化）



#### 代码实现：
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1791019423539-31de9351-50f0-48c8-bca7-434eb4318926.png" width="996.428531834059" alt="" title="" crop="0,0,1,1" id="u2730c06f" class="ne-image">

```python
import torch
import torch.nn as nn

BN = nn.BatchNorm1d(num_features=4)
linear1 = nn.Linear(4,5)
input = torch.randn(0,10,size=(10,4)).float
#将数据导入线性层处理
y = linear1(input)
#将线性层处理好数据交给激活函数
y = torch.relu(y)
#进行BN处理，将数据进行标准化
y = BN(y)
```
