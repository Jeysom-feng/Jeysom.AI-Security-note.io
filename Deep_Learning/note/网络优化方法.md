### 基于改变梯度的优化算法：
#### momentum算法（动量算法）：
##### 计算方式：
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1790926539433-2fa98381-4661-4fcc-b173-2571c2220c2d.png" width="323.21427287090444" alt="" title="" crop="0,0,1,1" id="u901d1a9a" class="ne-image">

s_t：本轮最终梯度	g_t：通过损失函数求偏导得出的梯度

β是调节历史梯度与当前梯度权重的参数，β越大则历史梯度的影响越大

##### 对梯度下降算法的改进：
在遇到鞍部以及下降平缓时，可以凭借历史梯度“冲出”鞍部，避免参数更新停滞

但是在解决局部极小值问题时十分有限，在遇到很深的局部极小值时，会出现冲不出去的问题

##### 代码实现：
```python
w = torch.tensor([1,0],required_grad=true,dtype=torch.float)
lossFunction=(w**2)/2.0.sum
#定义优化器
optimizer = torch.optim.SGD([w],lr=0.01,momentum=0.9)
optimizer.zero_grad()
optimizer.backward()
optimizer.step()
print("更新后的权重w:"%(w))
```

##### 缺点：
会使学习率过早、过量的降低，导致模型后期训练学习率过低，较难找到最优解

在s_t的计算中历史累计梯度与本轮计算梯度的平方的权重是一样的

##### 代码实现：
```python
w = torch.tensor([1,0],required_grad=true,dtype=torch.float)
lossFunction=(w**2)/2.0.sum
#定义优化器
optimizer = torch.optim.AdaGrad([w],lr=0.01)
optimizer.zero_grad()
optimizer.backward()
optimizer.step()
print("更新后的权重w:"%(w))
```

### 学习率衰减策略：
#### 固定间隔衰减：
```python
import torch
#定义优化器
optimizer =torch.optim.SGD([w],lr=0.1,momentum=0.9)
#定义学习率衰减调度器
scheduler=torch.optim.lr_scheduler.StepLR(optimizer,step_size=50,gamma=0.5)
```

#### 指定间隔衰减：
```python
import torch
#定义优化器
optimizer =torch.optim.SGD([w],lr=0.1,momentum=0.9)
#定义学习率衰减调度器
scheduler=torch.optim.lr_scheduler.MultiStepLR(optimizer,milestones=[50,100,160],gamma=0.5)
```

#### 指数学习率衰减：
lr=lr*（gamma**epoch）

```python
import torch
#定义优化器
optimizer =torch.optim.SGD([w],lr=0.1,momentum=0.9)
#定义学习率衰减调度器
scheduler=torch.optim.lr_scheduler.ExponentialLR(optimizer,gamma=0.5)
```
