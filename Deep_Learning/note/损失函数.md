


:::color4

### 2.二分类交叉熵
#### 公式：<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1790144788389-5d6f2029-0850-4465-ab25-b929e3908755.png" width="811.607139401746" alt="" title="" crop="0,0,1,1" id="u3d91d55c" class="ne-image">
#### 代码实现：
```python
import torch
import torch.nn as nn

##数据集真实值
y_true = torch.tensor([0,1,0],dtype=torch.float)        #表示第1，3条样本属于0类，第2条样本属于1类
#预测值
y_predict = torch.tensor([0.3678,0.8987,0.2788],dtype=torch.float)

#获取损失函数对象
loss = nn.BCELoss()
lossdata = loss(y_predict,y_true) #第一个参数是预测值，第二个参数是真实值
print(lossdata)
```



### 3.MAE(L1 loss)
#### 公式：
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1790146996588-bf7cdb1b-4571-4d33-baf7-3ab9609f4238.png" width="1106.2499952901687" alt="" title="" crop="0,0,1,1" id="u73fdbb62" class="ne-image">

#### 代码实现：
```python
import torch
import torch.nn as nn

y_true = torch.tensor([7,2,3]，dtype=torch.float,required_grad = true)
y_predict = torch.tensor([5,3,6],dtype=torch.float,required_grad = true)
cretirion = nn.L1Loss()
loss = cretirion(y_predict,y_true)
```

#### 缺点;
在梯度为零处不平滑，容易错过梯度最小处



### 4.MSE
#### 公式：
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1790147658171-5c0e7150-3ac0-435f-9f50-8dacf6d6738c.png" width="1000.8928528815812" alt="" title="" crop="0,0,1,1" id="u535b252f" class="ne-image">

#### 代码实现：
```python
import torch
import torch.nn as nn

y_true = torch.tensor([7,2,3]，dtype=torch.float,required_grad = true)
y_predict = torch.tensor([5,3,6],dtype=torch.float,required_grad = true)
cretirion = nn.MSELoss()
loss = cretirion(y_predict,y_true)
```

#### 缺点：
当预测值与真实值相差过大时，容易造成梯度爆炸

### 5.Smooth L1
#### 公式：
<img src="https://cdn.nlark.com/yuque/0/2026/png/62806879/1790147552072-6b46d95d-1b4a-4e94-be0a-07d7ce97415e.png" width="1130.357138044676" alt="" title="" crop="0,0,1,1" id="u1307ac45" class="ne-image">

#### 代码实现：
```python
import torch
import torch.nn as nn

y_true = torch.tensor([7,2,3]，dtype=torch.float,required_grad = true)
y_predict = torch.tensor([5,3,6],dtype=torch.float,required_grad = true)
cretirion = nn.SmoothL1Loss()
loss = cretirion(y_predict,y_true)
```

#### 优点：
既解决了L1loss的梯度为0不平滑问题，也解决了MSE梯度爆炸的问题
